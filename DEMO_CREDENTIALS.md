### 🏗️ **Setting Up Real Backend (Optional)**

If you want to connect to a real Supabase backend:

1. **Create Supabase Project**: Go to [supabase.com](https://supabase.com)
2. **Get Credentials**: Copy your project URL and anon key
3. **Update Environment**: Edit `.env.local` with real credentials:
   ```bash
   NEXT_PUBLIC_SUPABASE_URL=your_real_supabase_url
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your_real_supabase_key
   NEXT_PUBLIC_DEMO_MODE=false
   ```
4. **Restart Server**: The app will switch to real Supabase backend
